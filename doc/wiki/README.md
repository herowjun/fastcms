## 一句话理解 Fastcms

**一个用 Spring Boot 4.1 + JDK 21 + Vue3 构建的、内置"代码生成器 + 插件化 + 数据权限 + AI 集成 + 多语言"的现代化内容管理系统（CMS），核心能力（用户/角色/资源/菜单/部门）沉淀在 `service` 模块，内容管理（文章/页面/评论/附件/站点）沉淀在 `cms` 模块，运行时通过 PF4J 插件机制动态扩展业务能力。**
