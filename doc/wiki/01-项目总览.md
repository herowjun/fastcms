# 01 · 项目总览

## 1. 项目定位

**Fastcms**（`com.fastcms:fastcms`，版本 `${revision}=1.0.0-SNAPSHOT`，LGPL-3.0 开源）是一个**插件化、现代化、面向中后台的内容管理系统**，由广州小橘灯信息科技有限公司（`xjd2020`）维护，作者 `wjun_java@163.com`。

它的核心设计取向：

- **可二次开发**：内置代码生成器（`codegen`），一套表 → 完整 CRUD（Entity/Mapper/Service/Controller/UI）。
- **可插件化**：基于 PF4J 的插件运行时，业务功能（微信/支付/OAuth2/短信/站点管理…）以独立 jar 形式热插拔，无需改主工程。
- **可配置**：站点、菜单、角色、资源、权限、AI 模型、附件存储等均可在管理后台配置。
- **面向国内场景**：内置微信（公众号/小程序/扫码登录/分享）、支付宝/微信/银联支付、短信、EasyCaptcha 图形验证码、EasyTrans 多语言翻译。

## 5. 快速理解要点

1. **一个应用，两个安全域**：
   - `/fastcms/client/**` → HTTP Basic（公众号/小程序等客户端 API）
   - `/fastcms/api/admin/**` → JWT Bearer（管理后台 API）
   - 由 `FastcmsAuthConfig` 注册两条 `SecurityFilterChain`，按路径前缀路由。
2. **一个 jar，N 个插件**：`web` 打成 `fastcms-server.jar`，启动时扫描 `plugins/` 目录加载 PF4J 插件，插件可暴露 Controller、Mapper、配置项。
3. **一套表，自动生成**：`codegen` 模块读 MySQL/PG 等数据库的表，一键生成 Entity + Mapper + Service + Controller + 前端视图 + 菜单 SQL。
4. **数据权限 = SQL 重写**：`FastcmsDataPermissionInterceptor` 在 MyBatis `StatementHandler.prepare` 阶段用 JSqlParser 解析 SQL，按当前用户的部门/角色动态追加 WHERE 条件。
5. **多语言**：实体字段上标 `@Translate` + i18n 资源文件，EasyTrans 在序列化时自动翻译。
