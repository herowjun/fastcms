## 2. 双安全域（认证/鉴权）

`web/src/main/java/com/fastcms/web/security/FastcmsAuthConfig.java` 同时注册**两条** `SecurityFilterChain`，按 `@Order` 与请求路径前缀分流：

| SecurityFilterChain | 路径前缀 | 认证方式 | 说明 |
| --- | --- | --- | --- |
| `FastcmsAuthConfig`（admin，`@Order(1)`） | `/fastcms/api/admin/**` | **JWT**（Bearer Token，jjwt 0.11.2） | 管理后台 API，由 `JwtAuthTokenFilter` 解析并写入 `SecurityContext` |
| `FastcmsAuthServerConfig`（client） | `/fastcms/api/client/**` | **HTTP Basic** | 公众号/小程序等第三方客户端 API |

- 两条链都用 `SessionCreationPolicy.STATELESS`（无状态）。
- 登录入口：`LoginController.login`（验证码校验 + 图形验证码）→ 生成 JWT；`CaptchaController` 提供 easy-captcha 图形验证码。
- 方法级/接口级鉴权用自定义注解 `@Secured(resource="xxx:list", action=READ)`（`common/auth/Secured.java`），`resource` 即 `RESOURCE_NAME_*` 常量，`ActionTypes` 区分 READ/CREATE/UPDATE/DELETE。
- JWT 过滤器特例：`shouldNotFilterAsyncDispatch()` 返回 `false`，让 SSE 异步请求在 ASYNC dispatch 时也能重新解析 token（否则 SSE 结束会 500）。

## 3. 关键运行时流程

### 3.1 管理端请求流
```
浏览器 → /fastcms/api/admin/article/list
  → JwtAuthTokenFilter（解析 Bearer JWT，写 SecurityContext）
  → Spring Security 过滤器链
  → ArticleController.list()（@Secured 校验资源权限）
  → IArticleService（业务）
  → MyBatis-Plus Mapper
  → FastcmsDataPermissionInterceptor（SQL 注入部门/角色数据权限 WHERE）
  → 数据库
  → RestResult<Page<ArticleVo>> 返回
```

### 3.2 插件加载流（启动时）
```
Fastcms.java 启动
  → FastcmsPluginManager（PF4J）扫描 plugins/ 目录的 .jar / .class
  → 对每个插件：
       ControllerRegister.registry()    注册 @RestController 路由
       MapperRegister.registry()        注册 MyBatis Mapper
       WebAppConfigurerRegister         注册 WebMVC 配置
  → 插件方法上标 @PassFastcms 的路由自动加入 permitAll
  → 管理后台"插件"页可 启用/禁用/上传 插件（运行时动态）
```

### 3.3 数据权限流（SQL 重写）
```
MyBatis 执行 SELECT
  → FastcmsDataPermissionInterceptor.intercept()
      1. 只处理 SELECT
      2. 跳过 ignoreMappedStatementIds 配置
      3. 跳过 @IgnoreDataPermission 标记（IgnoreDataPermissionCache）
      4. JSqlParser 解析原 SQL
      5. DataPermissionSqlHandlerManager 按当前用户(部门/角色)生成追加条件
      6. 重写 BoundSql 后放行
```

## 5. 包组织约定（后端）

每个业务模块遵循统一包结构（`service` 与 `cms` 为例）：

```
com.fastcms.<module>/
├── controller/          # REST 控制器
│   ├── admin/           #   管理端（/fastcms/api/admin/...）
│   └── client/          #   客户端（/fastcms/client/...）
├── service/             # 业务接口 I*Service
├── service/impl/        # 业务实现 *ServiceImpl（继承 ServiceImpl<Mapper, Entity>）
├── mapper/              # MyBatis-Plus Mapper 接口
├── entity/              # 实体（@TableName 表名映射）
└── ...
```

约定要点：
- **Controller**：`@RestController` + `@RequestMapping(FastcmsConstants.ADMIN_MAPPING + "/xxx")`，方法标 `@Secured`。
- **Service 接口**：命名 `I*Service`，实现 `*ServiceImpl extends ServiceImpl<Mapper, Entity>`。
- **统一返回**：`RestResult<T>`（`common/model/RestResult`），分页用 MyBatis-Plus `Page<T>` + 自定义 `PageModel`。
- **实体**：`@TableName("xxx")`，主键 `@TableId`，多语言字段用 `@I18n`/资源文件。

## 6. 关键技术决策

| 决策 | 选型 | 理由（从代码/注释推断） |
| --- | --- | --- |
| 插件框架 | PF4J 3.13.0 | 支持运行时热插拔、独立 classloader、扩展点工厂 |
| 数据权限 | 自研 MyBatis 拦截器 + JSqlParser | 透明改写 SQL，业务代码零侵入 |
| 多语言 | 自研 `I18nUtils` + 资源文件 + 实体注解 | 不依赖 EasyTrans，字段级翻译 |
| 缓存 | Ehcache（jakarta）+ spring-cache | 本地缓存优先，无状态部署友好 |
| 全文检索 | Lucene 8.1.0（smartcn 中文分词） | 内置中文分析器 |
| 微信生态 | weixin-java（binarywang）4.5.0 | 公众号/小程序统一 SDK |
| 支付 | egzosn/pay-java 2.14.3 | 统一多支付渠道抽象 |
| AI | Spring AI 2.0.1（OpenAI + MCP + RAG） | 2026 新增，模型可后台配置 |
