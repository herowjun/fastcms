# 07 · 前端 UI（ui/）

## 1. 技术栈

- **框架**：Vue 3（Composition API）+ TypeScript + Vite 4
- **UI**：Element Plus
- **状态**：Pinia
- **路由**：Vue Router 4（`src/router/`：`backEnd.ts` 动态后台路由 + `frontEnd.ts` 前台路由）
- **多语言**：vue-i18n（`src/i18n/`）
- **富文本**：CKEditor5（主）+ WangEditor
- **图表**：ECharts（含 GL / 词云）
- **HTTP**：axios（`src/utils/` 封装拦截器，Bearer Token 注入）

## 3. 路由约定

- 后台动态路由由后端 `RouterController`（`/fastcms/api/admin/router`）按当前用户权限下发，前端 `backEnd.ts` 动态注册。
- 登录页、注册页为静态路由。
- 菜单表（`menu`）驱动侧边栏与权限。

## 4. 与后端交互

- 所有请求走 `/fastcms/api/admin/**`，axios 拦截器自动加 `Authorization: Bearer <token>`。
- 登录：`POST /fastcms/api/admin/login`（账号 + 密码 + 图形验证码）→ 返回 JWT。
- 401 响应 → 拦截器跳转登录页。

## 5. 构建

```bash
cd ui
npm install
npm run dev      # 开发（vite，代理到后端）
npm run build    # 产出 ui/dist
```

> 管理后台 SPA 与 `templates/`（FreeMarker 前台模板）是两套前端：
> - `ui/` = 后台管理（Vue3 SPA）
> - `templates/` = 前台内容展示（FreeMarker 服务端渲染，插件可扩展模板）
