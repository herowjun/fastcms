# 03 · 模块职责

主工程是 Maven 多模块（父 `fastcms`，`packaging=pom`），含 8 个 Maven 模块 + 2 个非 Maven 目录（`ui`、`templates`）。下面逐一说明。

## 1. Maven 模块清单

| 模块目录 | artifactId | 职责 |
| --- | --- | --- |
| `common` | fastcms-common | 公共基础：模型、异常、常量、鉴权注解、通用工具 |
| `core` | fastcms-core | 内核：MyBatis 基础类、Web 基础类、验证码、监控、反射 |
| `service` | fastcms-service | 基础业务：用户/角色/资源/菜单/部门/登录/系统 |
| `cms` | fastcms-cms | 内容管理业务：文章/分类/标签/评论/附件/单页/站点/订单 |
| `web` | fastcms-web | **可执行 Spring Boot 应用**（最终 `fastcms-server.jar`） |
| `codegen` | fastcms-codegen | 代码生成器（表 → CRUD 代码 + 菜单 SQL） |
| `plugins` | fastcms-plugins（主工程内） | 插件公共抽象（模板/注解），含 hello-world 示例插件 |
| `starters` | fastcms-starters | 9 个 Spring Boot Starter 的聚合模块 |
| `ui` | （npm 工程） | 前端 Vue3 管理后台 |
| `templates` | （资源目录） | FreeMarker 模板 / 前端 html 模板 |

## 2. common（fastcms-common）

**定位**：所有模块最底层的公共能力，**不含 Spring 业务**。

关键包（`com.fastcms.common`）：
- `model/`：`RestResult<T>`（统一返回）、`RestResultUtils`、`PageModel` 等
- `exception/`：`FastcmsException`（业务异常基类）、全局异常码
- `auth/`：`@Secured`（接口鉴权注解）、`ActionTypes`（READ/CREATE/UPDATE/DELETE）、`ResourceParser`（资源名解析器）
- `constants/`：`FastcmsConstants`（路径常量）
- `utils/`：`StrUtils` 等通用工具

关键常量（`FastcmsConstants.java`）：
```java
String API_PREFIX_MAPPING = "/fastcms/api";
String ADMIN_MAPPING      = API_PREFIX_MAPPING + "/admin";   // /fastcms/api/admin
String API_MAPPING        = API_PREFIX_MAPPING + "/client";  // /fastcms/api/client
String PLUGIN_MAPPING     = "/fastcms/plugin";
```
依赖：jsoup、jackson、commons-lang/io/beanutils/compress、Thumbnailator、zt-zip。

## 3. core（fastcms-core）

**定位**：Spring 内核封装——把 MyBatis、Web、FreeMarker、WebSocket、监控等基础能力打包，供 `service`/`cms` 使用。

关键包：
- `com.fastcms.core.mybatis`：MyBatis 基础（分页、逻辑删除、自动填充等配置）
- `com.fastcms.core.web`：Web 基础（CORS、静态资源、国际化 LocaleResolver、拦截器基类）
- 验证码（easy-captcha）、监控（micrometer prometheus/influx/elastic 注册器）、反射（reflections）

依赖：`spring-boot-starter-web / freemarker / websocket`、`fastcms-service`、easy-captcha、reflections、micrometer。

## 4. service（fastcms-service）

**定位**：平台**基础业务**（与内容无关的后台能力）。

关键包（`com.fastcms.service` + `com.fastcms.entity` + `com.fastcms.controller` 等）：
- **用户/认证**：`user`（实体 + Service + admin/client Controller）、`LoginController`、`CaptchaController`
- **权限**：`role`、`resource`、`permission`、`menu`（RBAC 资源/角色/菜单）
- **组织**：`department`、`department_user`（部门，数据权限的依据）
- **系统**：`config`（系统配置）、`order`/`payment`/`cashout`（订单/支付/提现，对接 payment-starter）
- **用户资产**：`user_amount`、`user_tag`、`user_openid`、`user_server_openid`

依赖：spring-boot-starter-security/validation/aspectj/cache、ehcache、`fastcms-common`、**6 个 starter**（plugin/payment/wechat/lucene/email/oauth2）。

> `service` 是 starter 的"宿主"——平台级能力（支付/微信/检索/邮件/OAuth2）在此统一装配。

## 5. cms（fastcms-cms）

**定位**：**内容管理**业务（CMS 核心）。

关键包（`com.fastcms.cms`）：
- **文章**：`Article`（实体）、`ArticleController`（admin）、`IArticleService`、`ArticleMapper`；含 `ArticleI18n` 多语言常量
- **分类/标签**：`ArticleCategory`、`ArticleTag`、关联表 `article_category_relation` / `article_tag_relation`
- **评论/点赞**：`ArticleComment`、`ArticleZan`、`SinglePageComment`
- **单页**：`SinglePage`（独立页面）
- **附件**：`attachment`
- **站点**：`site-manager`（多站点/多语言站点，由 site-manager-plugin 增强）

依赖：`spring-boot-starter-web`、`fastcms-core`。

## 6. web（fastcms-web）⭐ 最终交付

**定位**：唯一可执行 Spring Boot 应用，组装 `core + cms + ai-starter`，承载**安全配置、插件装载、过滤器、全局异常、启动类**。

关键包（`com.fastcms.web`）：
- `Fastcms.java`：`@SpringBootApplication` 启动类，`main()` 启动
- `config/`：`FastcmsConfiguration`（核心配置：CORS、FreeMarker 路径、插件目录、拦截器注册等）、`WebConfig`
- `security/`：`FastcmsAuthConfig`（admin/JWT）、`FastcmsAuthServerConfig`（client/Basic）、`TokenManager`（JWT 签发/校验）
- `filter/`：`JwtAuthTokenFilter`（JWT 解析）
- `handler/`：全局异常、统一返回包装
- `controller/`：登录、静态页、健康检查等 web 层控制器

资源：`application.yml`（dev 默认）、`application-prod.yml`（生产）、`i18n/` 多语言、`startup.sh/cmd`、`shutdown.sh/cmd`、`Dockerfile`、`docker-build/run.sh`。

打包产物：`fastcms-web-*-exec.jar` → 重命名 `fastcms-server.jar`（`build.sh`/`build.bat`）。

## 7. codegen（fastcms-codegen）

**定位**：代码生成器，**开发者工具**（非运行时必需）。

- 基于 `mybatis-plus-generator` + FreeMarker 模板
- 读取数据库表 → 生成 Entity / Mapper / Service / ServiceImpl / Controller / 前端视图 / 菜单 SQL
- 支持 MySQL 等数据源
- 入口在 `com.fastcms.codegen`

依赖：mybatis-plus-generator 3.5.16、`fastcms-mybatis-starter`、mysql-connector、freemarker。

## 8. plugins（主工程内 fastcms-plugins）

**定位**：**插件抽象层**（区别于独立仓库 `fastcms-plugins`）。
- 提供插件开发用的公共注解、模板、`@PassFastcms`（放行标记）等
- 含 `hello-world-plugin` 示例（依赖 `fastcms-core`，scope=provided）

> 真正的业务插件在独立仓库 `F:\wangjun\ideaProjects\fastcms-plugins`，见 [08-插件系统](./08-插件系统.md)。

## 9. starters（9 个 Starter）

`starters/` 聚合 9 个 Spring Boot Starter，每个封装一类横切能力：

| Starter | 能力 | 关键技术 |
| --- | --- | --- |
| `mybatis-starter` | MyBatis-Plus + **数据权限** | mybatis-plus-spring-boot4 3.5.16、jsqlparser-4.9 |
| `plugin-starter` | **PF4J 插件运行时** | pf4j 3.13.0 |
| `payment-starter` | 统一支付（微信/支付宝/银联） | egzosn/pay-java 2.14.3 |
| `wechat-starter` | 微信公众号/小程序 | weixin-java 4.5.0 |
| `lucene-starter` | 全文检索（中文 smartcn） | Lucene 8.1.0 |
| `email-starter` | 邮件发送 | spring-boot-starter-mail |
| `oauth2-starter` | OAuth2 客户端/资源/授权服务器 | spring-security-oauth2 |
| `ai-starter` | **Spring AI**（OpenAI/MCP/RAG） | spring-ai 2.0.1 |
| （聚合父）fastcms-starters | — | spring-boot-autoconfigure + common |

## 10. ui（前端，非 Maven）

独立 npm 工程，详见 [07-前端UI](./07-前端UI.md)。构建产物 `ui/dist` 由后端 `core`/`templates` 作为静态资源/FreeMarker 模板服务。

## 11. templates（非 Maven）

FreeMarker 模板与前端 html 模板资源目录。`build.sh` 会把 `templates/src/main/resources` 拷入 `dist/htmls`。
