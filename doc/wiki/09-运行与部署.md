# 09 · 运行与部署

## 1. 环境要求

| 项 | 要求 | 备注 |
| --- | --- | --- |
| JDK | **JDK 21** | 源码 `<maven.compiler.source>21</maven.compiler.source>`；Boot 4.1 最低要求 JDK 17，项目用 21 |
| Maven | 3.8+ | 多模块构建 |
| 数据库 | MySQL 8（默认）/ PostgreSQL / SQL Server / Oracle | 默认 `localhost:3308/fastcms`，root/123456 |
| 前端 | Node ≥ 16 / npm ≥ 7 | 仅构建 `ui/` 需要 |
| 端口 | 8080（默认 HTTP） | 可在 `application.yml` 改 `server.port` |

## 2. 数据库初始化

1. 建库：`CREATE DATABASE fastcms DEFAULT CHARACTER SET utf8mb4;`
2. 导入全量：`source doc/sql/fastcms.sql`（37 张表 + 初始数据）。
3. 升级场景：按 `doc/sql/fastcms-0.x.x.sql` 增量脚本顺序执行。

## 3. 后端运行（开发）

```bash
# 方式 A：IDE 直接运行启动类
com.fastcms.web.Fastcms   # web 模块，main()

# 方式 B：Maven
mvn spring-boot:run -pl web -am
```
- 默认 `spring.profiles.active: dev`，读 `application.yml`（dev 数据源 `localhost:3308`）。
- 缓存：`spring.cache.type: jcache` + `classpath:ehcache.xml`（本地 Ehcache）。

## 4. 前端运行（开发）

```bash
cd ui
npm install
npm run dev      # Vite 开发服务，代理到后端 8080
npm run build    # 产出 ui/dist
```

## 5. 生产打包与部署

### 5.1 一键打包
```bash
# Linux/Mac
sh build.sh
# Windows
build.bat
```
- 执行 `mvn clean install -Dmaven.test.skip=true`。
- 组装 `dist/`（`.dist/`）目录：
  ```
  dist/
  ├── fastcms-server.jar      # web/target/fastcms-web-*-exec.jar 重命名
  ├── config/                 # application-prod.yml
  ├── plugins/                # 插件投放目录
  ├── htmls/                  # templates/src/main/resources 前台模板
  ├── logs/
  └── upload/                 # 附件目录（build.sh；附件固定 ~/fastcms/upload，FASTCMS_HOME 可覆盖）
  ```

### 5.2 启动 / 停止
- Linux：`./startup.sh`（JVM：`-Xms512m -Xmx512m -Xmn256m`，`--spring.profiles.active=prod`，日志 `logs/fastcms.log`）
- Windows：`startup.cmd`
- 停止：`shutdown.sh` / `shutdown.cmd`

> ⚠️ 已知问题：`startup.sh` 末行 `nohup $JAVA ${JAVA_OPT} fastcms.fastcms` 在 `${JAVA_OPT}`（已含 `-jar ...jar`）后又多追加了 `fastcms.fastcms` 参数，属于脚本笔误；`startup.cmd` 写法正确，生产建议以 `.cmd` 或手动 `java -jar fastcms-server.jar --spring.profiles.active=prod` 为准。

### 5.3 配置说明（application-prod.yml）
- 生产需覆盖数据源（库地址/账号）、`fastcms.auth.token.secret-key`、`expire.seconds`。
- `fastcms.security.ignore.urls`：免登录白名单（登录/注册/验证码/微信登录/websocket）。
- `fastcms.config.ignore.keys`：对外隐藏的配置 key（如 `wechat_mch_secret`）。

## 6. Docker 部署

```bash
# 构建
./docker-build.sh <version>     # docker build . -t wangjun/fastcms:<version>
# 运行
./docker-run.sh <version>       # docker run -d -p 8080:8080 --network=host --name fastcms-<version> -e SPRING_PROFILES_ACTIVE=prod wangjun/fastcms:<version>
```

> ⚠️ 已知不一致：`web/Dockerfile` 基础镜像为 `FROM openjdk:17`，而项目要求 JDK 21。直接构建可能因语言版本不足失败，建议基础镜像升级为 `eclipse-temurin:21` 等 JDK21 镜像。镜像名约定 `wangjun/fastcms:${project.version}`。

## 7. 插件部署

- 插件 jar 投放到运行目录 `plugins/`（或 `web/src/main/resources/plugins` 开发态）。
- 启动自动加载已启用插件；也可在后台"插件"页运行时上传/启停（见 [08-插件系统](./08-插件系统.md)）。
- 业务插件构建：在 `fastcms-plugins` 仓库 `mvn clean install`，产物 jar 复制到主工程 `plugins/`。

## 8. 健康检查与日志

- 日志：logback 配置 `classpath:META-INF/logback/fastcms.xml`，输出到 `logs/`。
- 监控：micrometer（Prometheus / InfluxDB / Elastic 注册器，core 模块），按需启用。
- API 文档：`smart-doc-maven-plugin`（配置 `web/src/main/resources/smart-doc.json`）生成接口文档。
