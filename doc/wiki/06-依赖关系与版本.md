# 06 · 依赖关系与版本

## 1. 模块依赖矩阵（Maven）

```
web ──► core, cms, ai-starter, jjwt
core ──► service, spring-web/freemarker/websocket, easy-captcha, micrometer, reflections
cms ──► core
service ──► common, plugin-starter, payment-starter, wechat-starter,
            lucene-starter, email-starter, oauth2-starter, ehcache
common ──► (第三方工具库，无内部依赖)
codegen ──► mybatis-starter, mybatis-plus-generator, freemarker
plugins(主工程) ──► hello-world-plugin ◄── core (provided)
starters/* ──► common, spring-boot-autoconfigure
```

依赖方向严格自上而下，**无循环依赖**。

## 4. 构建产物依赖链

```
mvn clean install
  └─► web/target/fastcms-web-1.0.0-SNAPSHOT-exec.jar
        （spring-boot-maven-plugin repackage，executable）
build.sh / build.bat
  └─► dist/fastcms-server.jar + config/ + plugins/ + htmls/ + logs/ + upload/
```
