# 08 · 插件系统

## 1. 架构

Fastcms 基于 **PF4J 3.13.0** 实现插件化，分两层：

- **插件抽象层**（主工程 `plugins/` 模块）：插件开发基类、`@PassFastcms` 放行注解、FreeMarker 视图、示例 `hello-world-plugin`。
- **插件运行时**（`starters/plugin-starter`）：PF4J 管理器 + 各类 Register（Controller/Mapper/扩展点/FreeMarker/拦截器）。
- **业务插件仓库**（独立工程 `F:\wangjun\ideaProjects\fastcms-plugins`）：16 个业务插件。

## 2. 插件加载机制（启动 + 运行时）

### 启动加载
```
Fastcms 启动
  └─► FastcmsPluginManager（PF4J）
        扫描插件目录（默认 plugins/，可配）
        支持 .jar（独立 classloader）与 .class
        对每个已启用插件：
          ControllerRegister        → @RestController 路由进 Spring MVC
          MyBatisMapperRegister     → MyBatis Mapper 进 SqlSessionFactory
          ExtensionsRegister        → PF4J 扩展点
          ComponentRegister         → Spring Bean
          FreeMarkerViewRegister    → 插件 FreeMarker 视图/模板
          DirectiveRegister         → 自定义 FreeMarker 指令
          InterceptorRegister       → 插件拦截器
          FastcmsTaskRegister       → 定时任务
        @PassFastcms 方法路径 → PluginPermitAllManager → Security permitAll
```

### 运行时热插拔
- 管理后台"插件"页（`PluginController` + `PluginManagerService`）支持：
  - 上传插件 jar
  - 启用 / 禁用
  - 卸载
- 插件独立 classloader，互不污染；禁用即卸载路由与 Bean。

## 3. 插件开发约定

- 插件继承 `PluginBase` 或标注 PF4J `@Plugin`。
- 暴露 REST 接口：普通 `@RestController`（经 `ControllerRegister` 注册），路径前缀 `FastcmsConstants.PLUGIN_MAPPING`（`/fastcms/plugin`）。
- 无需登录的接口：方法/类标 `@PassFastcms`。
- 插件自带 MyBatis Mapper、FreeMarker 模板（放插件资源 `templates/`）均被自动装配。
- 依赖 `fastcms-core` 时 `scope=provided`（由宿主提供）。

## 4. 业务插件清单（`fastcms-plugins/plugins/`，16 个）

| 插件 | 能力 |
| --- | --- |
| `hello-plugin` | 示例（Hello World，开发入门） |
| `site-manager-plugin` | **多站点/多语言站点管理**（`SiteInfo`/`SiteMenu`/`SiteCategory`） |
| `aliyun-oss-plugin` | 阿里云 OSS 存储 |
| `article-field-plugin` | 文章扩展字段 |
| `gen-html-plugin` | 生成静态 HTML |
| `group-buy-plugin` | 团购 |
| `order-commission-plugin` | 订单佣金 |
| `pay-download-plugin` | 支付后下载（付费内容） |
| `wechat-pay-plugin` | 微信支付 |
| `wechat-mp-share-plugin` | 公众号分享 |
| `wechat-mp-oauth2-plugin` | 公众号 OAuth2 授权 |
| `wechat-mp-scan-qrcode-login-plugin` | 微信扫码登录 |
| `wxapp-manager-plugin` | 小程序管理 |
| `phone-login-plugin` | 手机号登录 |
| `oauth2-server-plugin` | OAuth2 授权服务器 |
| `url-whitelist-plugin` | URL 白名单 |

> 每个插件是独立 Maven 子模块（`plugins/` 下 16 个 `<module>`），统一由 `plugins-root` 父 pom 管理，构建产物为 jar 投放到主工程 `plugins/` 目录。

## 5. 插件与主工程的关系

```
fastcms（主工程）                    fastcms-plugins（插件仓库）
  plugins/ (抽象+示例)                  main/ (插件公共库)
  starters/plugin-starter (运行时)      plugins/ (16 个业务插件)
  web/plugins/ (插件投放目录)            templates/ (插件模板资源)
         ▲                                   │
         └──────── 构建后 jar 投放 ◄──────────┘
```
