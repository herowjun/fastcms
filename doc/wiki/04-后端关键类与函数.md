# 04 · 后端关键类与函数

> 按"启动 → 安全 → 插件 → 数据 → 业务"的主线组织。路径均相对仓库根。

## 1. 启动与全局配置（web 模块）

### `com.fastcms.web.Fastcms`
`web/src/main/java/com/fastcms/web/Fastcms.java`
- `@SpringBootApplication(exclude = {…})`：显式排除 **Spring AI 2.x 的 OpenAI 全套自动配置**（`ChatClientAutoConfiguration`、`OpenAiChat/Embedding/Image/Audio/ModerationAutoConfiguration`）。
  - 原因（源码注释）：Spring AI 2.x 的 OpenAI 自动配置 `matchIfMissing=true` 且强制要求 `apiKey`；而 fastcms 的模型**全部由数据库配置动态构建**（`AiModelConfigServiceImpl.buildChatModel`），不走自动装配的 ChatModel/EmbeddingModel Bean。
- `@ComponentScan("com.fastcms")`：扫描全部 `com.fastcms` 包（含各 starter、cms、service）。
- `@EnableScheduling`：开启定时任务。
- `main()`：`SpringApplication.run(Fastcms.class, args)`。

### `com.fastcms.web.config.FastcmsConfiguration`
`web/src/main/java/com/fastcms/web/config/FastcmsConfiguration.java`
核心装配（约 17KB），负责：
- FreeMarker 模板路径（`templates/`、插件模板）
- 插件目录、CORS、静态资源、拦截器、国际化 `LocaleResolver`
- 注册全局异常处理器、`WebMvcConfigurer` 相关

## 2. 安全与认证（web 模块）

### `com.fastcms.web.security.FastcmsAuthConfig`
- admin 端 `SecurityFilterChain`，匹配 `/fastcms/api/admin/**`，`@Order(1)`，无状态。
- `permitAll`：登录/注册/验证码等放行路径（来自 `fastcms.security.ignore.urls`）+ 插件 `@PassFastcms` 路由（`PluginPermitAllManager`）。
- 其余需认证，`AuthenticationEntryPoint` 返回 401 JSON。

### `com.fastcms.web.security.FastcmsAuthServerConfig`
- client 端 `SecurityFilterChain`，匹配 `/fastcms/api/client/**`，**HTTP Basic** 认证，无状态。

### `com.fastcms.web.security.TokenManager`
- JWT 签发 / 校验（jjwt 0.11.2）。
- `secret-key` 与 `expire.seconds` 来自 `application.yml`（`fastcms.auth.token.*`）。

### `com.fastcms.web.filter.JwtAuthTokenFilter`
- 继承 `OncePerRequestFilter`，解析 `Authorization: Bearer <token>` → `TokenManager` 校验 → 写 `SecurityContext`。
- 重写 `shouldNotFilterAsyncDispatch()` 返回 `false`：让 SSE（`text/event-stream`）异步请求在 ASYNC dispatch 阶段也重新解析 token，避免 SSE 结束时 500。

### 登录/验证码控制器
- `controller/admin/…`（service 模块）`LoginController`：`login`（图形验证码校验 + 用户名密码）→ 签发 JWT。
- `CaptchaController`：easy-captcha 生成/校验图形验证码。

### 鉴权注解（common 模块）
`com.fastcms.common.auth.Secured`（`common/src/main/java/com/fastcms/common/auth/Secured.java`）
```java
@Secured(resource = "xxx", action = ActionTypes.READ)
```
- `resource`：资源名（`RESOURCE_NAME_*` 常量，如 `article`、`user`）。
- `action`：`ActionTypes`（READ / CREATE / UPDATE / DELETE）。
- 由 `ResourceParser` 解析，结合 RBAC（用户→角色→资源）做方法级鉴权。

## 3. 插件运行时（starters/plugin-starter）

`com.fastcms.plugin` 包（`starters/plugin-starter/src/main/java/com/fastcms/plugin/`）：

| 类 | 职责 |
| --- | --- |
| `FastcmsPluginManager` | PF4J 插件管理器：扫描 `plugins/` 目录（`.jar`/`.class`），加载/卸载/启停 |
| `PluginManagerService` | 对外 Service，供管理后台"插件"页调用（上传/启用/禁用） |
| `PluginRegister` / `CompoundPluginRegister` | 注册入口，聚合多个 Register |
| `register/ControllerRegister` | 把插件里的 `@RestController` 注册进 Spring MVC 路由 |
| `register/MyBatisMapperRegister` | 注册插件 MyBatis Mapper |
| `register/ExtensionsRegister` / `ComponentRegister` | 注册插件扩展点 / 组件 Bean |
| `register/FreeMarkerViewRegister` / `DirectiveRegister` / `InterceptorRegister` | 注册 FreeMarker 视图/指令/拦截器 |
| `PassFastcms` | 注解：标记插件方法无需认证（自动加入 permitAll） |
| `PluginPermitAllManager` | 收集 `@PassFastcms` 路径，喂给 Security 链 |
| `PluginBase` / `PluginApplicationUtils` | 插件开发基类 / 工具 |
| `extension/FastcmsExtensionFactory` | PF4J 扩展工厂（区分 Spring / 传统扩展） |
| `view/PluginFreeMarker*` | 插件 FreeMarker 视图解析 |

> 机制详见 [08-插件系统](./08-插件系统.md)。

## 4. 数据访问与数据权限（starters/mybatis-starter + core）

### `com.fastcms.mybatis.interceptor.FastcmsDataPermissionInterceptor`
`starters/mybatis-starter/.../mybatis/interceptor/FastcmsDataPermissionInterceptor.java`
MyBatis `Interceptor`，实现**行级数据权限**：
```
intercept(invocation):
  1. 仅处理 SELECT 语句
  2. 命中 fastcms.mybatis.ignore.mappedStatementIds → 跳过
  3. 命中 @IgnoreDataPermission（IgnoreDataPermissionCache）→ 跳过
  4. JSqlParser 解析原 SQL
  5. DataPermissionSqlHandlerManager 按当前用户(部门/角色)生成 WHERE 条件
  6. 重写 BoundSql 的 SQL 后放行
```
- 配置项 `fastcms.mybatis.ignore.mappedStatementIds`（`application.yml` 中如 `selectById, getArticleById, pageArticleZan, ArticleCategoryMapper.selectList`）。

### core 模块 MyBatis 基础
`core/src/main/java/com/fastcms/core/mybatis/`
- 分页插件、逻辑删除、字段自动填充（创建/更新时间、创建人）等 MyBatis-Plus 配置。

## 5. 业务控制器（cms / service 模块）

> 每个业务域遵循 `controller/admin/*Controller`（管理端）+ `service/*` + `mapper/*` 三层。

### 典型示例：文章
`cms/src/main/java/com/fastcms/cms/controller/admin/ArticleController.java`
```java
@RestController
@RequestMapping(FastcmsConstants.ADMIN_MAPPING + "/article")
public class ArticleController {
    @Autowired IArticleService articleService;

    @GetMapping("/list")
    @Secured(resource = "article", action = ActionTypes.READ)
    public RestResult<Page<ArticleVo>> list(ArticleQueryVo vo) { … }
    // create / update / delete / detail …
}
```
- 统一返回 `RestResult<T>`；分页用 MyBatis-Plus `Page<T>`。
- 实体 `cms/entity/Article.java`（`@TableName("article")`）。

### 各业务域控制器（service 模块）
`service/src/main/java/com/fastcms/controller/admin/`：
`UserController`、`RoleController`、`ResourceController`、`PermissionController`、`DepartmentController`、`ConfigController`、`OrderController`、`AttachmentController`、`PluginController`、`RouterController`、`AiModelConfigController`、`AiArticleController`、`AiTemplateController`、`AiUsageController`。
- `controller/api/PaymentCallbackController`、`WechatMessageCallbackController`：支付/微信回调（无需认证）。

### service 实体（`service/.../entity/`，对应 `doc/sql/fastcms.sql` 37 张表）
`User`、`Role`、`Resource`、`Permission`、`Department`、`Config`、`Attachment`、`Order`/`OrderItem`/`OrderInvoice`、`PaymentRecord`、`UserAmount`/`UserAmountPayout`/`UserAmountStatement`、`UserOpenid`、`UserServerOpenid`、`UserTag`、`AiModelConfig`、`AiTemplateFile`、`AiTemplateFileBackup`、`AiTemplateMessage`、`AiTemplateSession`、`AiUsageLog`、`AiArticleOpLog`、`Menu`。

## 6. AI 能力（starters/ai-starter，2026 新增）

`com.fastcms.ai`（`starters/ai-starter/src/main/java/com/fastcms/ai/`）：
- `service/impl/AiModelConfigServiceImpl`：**从数据库构建 ChatModel/EmbeddingModel**（`buildChatModel`），模型可后台动态增删改。
- `template/`：AI 模板生成（`TemplateGenPromptBuilder`、`PageSpecParser`、`PageSpecRenderer`、`ComponentGenPromptBuilder`）——AI 生成前端页面/组件。
- `article/AiArticleGenServiceImpl`：AI 文章生成/改写。
- `component/`：页面组件注册（`ComponentRegistry`、`TokenEngine`、`TailwindPackProvider`、`PageSpec*`）。
- `tool/`：AI 工具注册（`AiTool`、`AiToolRegistry`、`AiToolPluginRegister`、`AiToolCallbackProvider`）——MCP/Function Call。
- `audit/`：AI 用量与配额（`AiUsageRecorder`、`AiQuotaChecker`）。
- `support/AiApiKeyCipher`：API Key 加解密存储。

## 7. 统一返回与异常

- `com.fastcms.common.model.RestResult<T>`：所有 Controller 的统一响应包装（code/message/data）。
- `com.fastcms.common.exception.FastcmsException`：业务异常基类，全局异常处理器捕获后转 `RestResult`。
