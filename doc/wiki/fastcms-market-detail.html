安装与使用

上传插件 jar后台「插件」页上传下载的 jar 包，系统自动安装并注册能力
激活授权码在插件详情页粘贴购买获得的授权码，本地验签生效（官网不可达也不影响激活）
配置商户参数后台「支付网关」填入微信支付商户号 / API 密钥 / 证书，即收款

常见问题

授权码会过期吗？
按购买档位生效（示例 1 年 / 3 年）。到期前 7 天后台会提醒续费，续费后授权码自动续期；到期未续费时仅该插件功能停用，站点本身不受影响。
一个授权码能用几个站点？
一个授权码绑定一个站点。多站点请按需购买对应数量，或在购买时选择多站点档位（以购买页选项为准）。
FastCMS 升级后还能用吗？
以本页「版本兼容」表为准。插件与核心解耦，核心升级不改动插件；插件随版本更新提供新版本 jar，授权码有效期内免费下载更新。
