快速开始

FastCMS是一个基于 Java的高性能内容管理系统，使用 FreeMarker模板引擎渲染页面。

环境要求

  • Java11+
  • Maven3.6+
  • MySQL5.7+ / PostgreSQL12+

安装步骤

  1. 从 GitHub克隆项目
  2. 配置 application.yml数据库连接
  3. 执行 mvn clean package打包
  4. 启动 jar包即可
git clone https://github.com/fastcms/fastcms.git
cd fastcms
mvn clean package -DskipTests
java -jar target/fastcms.jar

模板开发

FastCMS模板基于 FreeMarker语法，支持自定义指令和宏定义。模板文件放置在 templates/目录下。

提示：所有静态资源必须通过 ${'$'}{ctx()}前缀引用，确保路径正确解析。

插件开发

插件是 FastCMS的核心扩展机制。每个插件是一个独立的 Maven模块，实现 FastPlugin接口即可。

public class MyPlugin implements FastPlugin {
 @Override
 public void onInit(PluginContext ctx) {
 //插件初始化
 }

 @Override
 public void onRender(RenderContext ctx) {
 //渲染钩子
 }
}

核心指令

指令用途示例
articleListTag文章列表<@articleListTag count=10/>
menuTag站点菜单<@menuTag/>
formatTime时间格式化<@formatTime value=now format="yyyy-MM-dd"/>
seoTagSEO配置${'$'}{seoTag("website_title")}
